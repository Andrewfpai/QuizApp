# QuizApp (Recall)

A dark-theme practice quiz app. Ask any AI for a quiz using the prompt in `LLM-PROMPT.txt`, paste or upload the JSON, and practice, on your computer or phone, online or offline.

- No build step: it's a static site (`index.html` + a few files), so you can deploy it as-is to Vercel, Netlify or GitHub Pages.
- Installable on your phone from the browser, and works offline.
- Optional sync between devices through Supabase. Fill in `config.js` to turn it on.

Setup steps are in [SETUP.md](SETUP.md).
